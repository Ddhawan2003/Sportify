# Sportify - Centralized Sports & Fitness Platform  

**[sportifyhq.vercel.app](https://sportifyhq.vercel.app)**  

Sportify is a comprehensive web application designed to be the ultimate platform for sports and fitness enthusiasts. From live sports stats to personalized workout tracking and tailored nutrition insights, Sportify brings all your fitness and sports needs into one seamless experience.  

## Features  
- **Live Sports Statistics**: Stay updated with real-time data on players, teams, and matches.  
- **Personalized Workout Tracking**: Set and track custom goals with detailed progress visualizations.  
- **Tailored Nutrition Insights**: Plan and manage your meals with micronutrient breakdowns and calorie goals.  
- **"Notion-like" Interface**: Effortlessly manage your fitness, sports, and nutrition data with a user-friendly layout.  
- Built on the **MERN stack** (MongoDB, Express, React, Node.js) for real-time updates and scalability.

## Set-Up  

### Getting Started  
To run Sportify locally, make sure you have **Docker** installed.  

1. Clone the repository:  

2. Build and run the application using Docker Compose:  
   ```bash  
   # Ensure Docker is running on your system  
   docker-compose up --build  
   ```  

3. The application will be available at `http://localhost:3000`.
